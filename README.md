# Stroke-Detection-Using-Brain-MRI
## 🧪 Model Architecture

- **DenseNet121** and **ResNet50** fine-tuned using transfer learning
- Binary classification (stroke vs. no stroke)
- Input: MRI images resized to 224×224
- Output: Probability of stroke presence

## 🛠️ Technologies Used

- Python
- PyTorch
- scikit-learn
- NumPy, pandas
- Matplotlib, Seaborn

## 📊 Evaluation Metrics

- Accuracy
- Precision & Recall
- F1 Score
- AUC-ROC Curve
